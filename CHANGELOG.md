# Changelog

## [0.1.0] - 2026-10-05
First version for keypad phones, based on Fossify Calculator 1.4.0.

### Added
- Calculations typed on the keypad like Calc-U-Later: `*` puts in an operator and turns it into the next one, `#` is
  the decimal point, OK or the call key shows the result
- New calculation engine with the correct order of operations, %, power, square root and parentheses
- Symbol palette on a held `*`: square tiles laid out like the keypad, picked by digit or arrows and OK
- History above the input, ↑ / ↓ go through it; it's cleared when the app is closed
- Bottom bar with three tabs switched by ← / →: calculator, unit converter, settings
- Unit converter for keys: ↑ / ↓ unit row, ← / → unit, `*` swap, "Use in the calculator"
- Copy the result from the Menu, settings and About screen for keys, blue app icon

### Removed
- The on-screen button pad and the home screen widget
